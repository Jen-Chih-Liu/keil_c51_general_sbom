# Reference: Keil C51 Build Artifact Formats & Structure

This document details the build artifacts generated by Keil C51 and how the SBOM generator parses them to extract dependency evidence.

---

## 1. Project Configuration: `w78_std_8051.uvproj`

XML project descriptor file for Keil µVision.

- **Key Elements**:
  - `/Project/Targets/Target/TargetOption/TargetCommonOption/Device`: Target MCU name (`W78E052D`).
  - `/Project/Targets/Target/TargetOption/TargetCommonOption/Vendor`: Silicon vendor (`Nuvoton`).
  - `/Project/Targets/Target/TargetOption/TargetCommonOption/Cpu`: Memory and clock definitions (`IRAM(0x00-0xFF) IROM(0x0000-0x1FFF) CLOCK(40000000)`).
  - `/Project/Targets/Target/TargetOption/Target51/Target51Misc/MemoryModel`: Memory model (`0` for Small).
  - `/Project/Targets/Target/TargetOption/TargetCommonOption/AfterMake/RunUserProg1`: Hook trigger flag.

---

## 2. Linker Map File: `Listings\w78_std_8051.m51`

Generated by Keil `BL51.exe` detailing memory layouts and linked modules.

- **Header Section**:
  - Tool version (e.g. `BL51 BANKED LINKER/LOCATER V6.22.4.0`).
  - Memory model (e.g. `MEMORY MODEL: SMALL`).
- **`INPUT MODULES INCLUDED:` Section**:
  - Plaintext list of all participating binary object files and libraries.
  - Syntax: `ABSOLUTE_PATH (MODULE_NAME)`.
  - Example:
    ```text
    INPUT MODULES INCLUDED:
      PROJECT\OBJECTS\STARTUP.OBJ (?C_STARTUP)
      PROJECT\OBJECTS\MAIN.OBJ (MAIN)
      C:\USERS\TESTER\APPDATA\LOCAL\KEIL_V5\C51\LIB\C51S.LIB (?C_INIT)
      C:\USERS\TESTER\APPDATA\LOCAL\KEIL_V5\C51\LIB\C51S.LIB (?C?UIDIV)
      C:\USERS\TESTER\APPDATA\LOCAL\KEIL_V5\C51\LIB\C51S.LIB (?C?SLCMP)
    ```
- **SBOM Extraction Strategy**:
  - Entries ending in `.LIB` are categorized as implicit runtime libraries (`library`), and parenthesized names are recorded as `keil:linked_module`.
  - Entries ending in `.OBJ` are matched to project source files.

---

## 3. Compiler / Assembler Listings: `Listings\*.lst`

Generated by `C51.exe` and `A51.exe` during compilation.

- **`main.lst` Header**:
  - Compiler executable version: `C51 COMPILER V9.60.7.0`.
  - Command-line parameters: `INCDIR(...)`, `OBJECT(...)`, etc.
- **`STARTUP.lst` Header**:
  - Assembler executable version: `A51 MACRO ASSEMBLER V8.2.7.0`.

---

## 4. Master Toolchain Configuration: `TOOLS.INI`

Located at the root of the Keil installation (e.g., `C:\Users\tester\AppData\Local\Keil_v5\TOOLS.INI`).

- **`[C51]` Section**:
  - `PATH`: Path to C51 toolchain.
  - `VERSION=V9.61`: Official suite release version.
- **SBOM Extraction Strategy**:
  - Used as the overarching suite version string (`suite_version`).

---

## 5. Intel HEX Firmware Image: `Objects\w78_std_8051.hex`

ASCII hexadecimal representation of the machine code generated by `OH51.exe`.

- Forms the Root Application Component of the SBOM.
- Cryptographic hashes (SHA-256, SHA-1, MD5) are recorded to establish binary integrity.
